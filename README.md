# Agent Orchestration Study Example

This repository contains a dependency-free Python study example for Chapter 5,
"Orchestration", from *Building Applications with AI Agents*.

The example demonstrates:

- Reflex agent behavior
- Semantic tool selection
- Hierarchical tool selection
- Parallel tool execution
- Chain workflow
- Graph workflow
- Context engineering

## Run

```bash
python3 agent_orchestration_study_example.py
```

The code intentionally uses local functions instead of paid external APIs, so it
is easy to run during a study presentation.
